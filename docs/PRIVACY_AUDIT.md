## 程式在使用者電腦保留的資料

- 歷史文字、OCR 結果及筆記存於 `data/app.db`；原圖、縮圖、標註及匯出檔存於對應的 `data/` 子目錄。自訂儲存位置時以設定顯示的實際目錄為準。
- 設定存於 `config/settings.json`；`logs/app.log` 按日輪替，最多保留 30 份舊 log。Log 可能含檔案路徑、字元數、標籤名稱及錯誤資訊。
- 正常執行路徑未發現自動上傳 OCR 圖片、文字或手寫筆跡的 HTTP 程式碼；ONNX telemetry 已停用。這不等於本次進行了完整封包側錄。
- 不要把整個 `data/`、`config/` 或 `logs/` 目錄直接附到公開 issue。回報問題時先移除實際文件、帳號、個人路徑及無關文字。Windows／第三方剪貼簿同步是另一條資料傳送管道，請依自己的系統設定決定是否啟用。

## 範圍限制

未涵蓋不可達 Git 物件、GitHub 端全部 cache／fork、全部舊 Actions console，或所有既有 EXE 與封存檔的二進位內容。格式掃描可能漏掉未知、編碼或拆分的憑證；若日後確認有真實金鑰，應先撤銷／輪替，再處理 Git 歷史與既有附件。
